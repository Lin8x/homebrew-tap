# Homebrew tap for FluidMessages

Install [FluidMessages Web](https://github.com/Lin8x/FluidMessages) on a Mac with Apple silicon:

```sh
brew install --cask lin8x/tap/fluidmessages-web
```

Update it with `brew upgrade --cask fluidmessages-web`. This tap is updated automatically on every FluidMessages release.

FluidMessages Web isn't notarized by Apple yet, so the cask removes macOS's quarantine flag after installing. To check your download first, see [How to check any download](https://github.com/Lin8x/FluidMessages/blob/main/docs/verify.md).

## OpenDirectory Admin Center

Install the [OpenDirectory](https://github.com/Lin8x/OpenDirectory) Admin Center on any Mac (Apple silicon or Intel):

```sh
brew install --cask lin8x/tap/opendirectory
```

It updates itself from GitHub Releases, and this tap is updated on every OpenDirectory release. The app isn't notarized by Apple yet, so the cask removes macOS's quarantine flag after installing.
